## Findings

1. **Theme stored twice** (low)
   `MainActivity.kt:51` (SharedPreferences `recording`/`theme`) and `store.js:3` (`localStorage` `recording`). The native side needs its copy to colour the bars before the page loads, and `app.js` re-sends the page's choice on every start, so they can't drift for long. Keep it in mind as more settings arrive: only settings the native side needs before the page loads should be mirrored.
   *Fix (S, later):* none needed now; if a second native setting appears, send the whole settings object through one bridge call instead of one method per setting.

2. **Release build not checked** (low)
   `app/build.gradle.kts:16`. R8 is on and the default rules keep `@JavascriptInterface` methods, but `assembleRelease` hasn't been run or tried on a phone. A shrinking problem would only show up there.
   *Fix (S):* build the release variant once and tap the theme buttons; the colours of the bars should follow.

3. **Gradle 8.14.7 available** (low)
   `gradle/wrapper/gradle-wrapper.properties:4`, lint `AndroidGradlePluginVersion`. It's a patch release with no known issue for this app; same version as the other projects.
   *Fix (S):* update when the other projects move, with the new `distributionSha256Sum`.
